# Proyek 4 — Buku Tamu Berbasis File

## Deskripsi
Aplikasi buku tamu sederhana menggunakan PHP dan JSON tanpa database.

## Fitur
- Menambahkan pesan tamu.
- Validasi nama, email, dan pesan.
- Menyimpan data ke file JSON.
- Menampilkan daftar pesan terbaru.
- Menghapus pesan tamu.
- Mengamankan output HTML menggunakan htmlspecialchars.

## Teknologi
- PHP
- HTML
- JSON
- XAMPP

## Cara Menjalankan
1. Simpan folder proyek di dalam htdocs.
2. Aktifkan Apache di XAMPP.
3. Buka http://localhost/portofolio-junior-web/proyek-4-buku-tamu/

## Struktur Folder
- index.php
- functions.php
- data/tamu.json
- README.md
