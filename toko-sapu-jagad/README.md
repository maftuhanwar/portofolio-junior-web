# Proyek PBL Hari 2 — Landing Page Toko Sapu Jagad

## Tema
Profil UMKM: Toko Sapu Jagad, usaha penjualan alat kebersihan dan jasa pemotongan rumput.

## Daftar halaman
- `index.html` — halaman utama dengan navigasi, profil, produk/layanan, galeri, tabel harga, dan formulir kontak.
- `tentang.html` — profil lengkap usaha.

## Struktur folder
```text
toko-sapu-jagad/
├── index.html
├── tentang.html
├── README.md
└── images/
    ├── logo.png
    ├── sapu-rayung.jpg
    ├── sapu-ijuk.jpg
    ├── sapu-lidi.jpg
    ├── alat-pel.jpg
    ├── keset.jpg
    └── tempat-sampah.jpg
```

## Sumber gambar
File gambar pada folder `images/` perlu diisi dengan foto milik sendiri atau gambar berlisensi bebas. Catat sumber dan lisensi setiap gambar yang digunakan. Gambar saat ini merupakan nama file contoh dan belum disertakan.

## Catatan sebelum dipublikasikan
- Periksa ulang alamat, akun media sosial, harga, dan informasi layanan.
- Harga Rp10.000 untuk sapu ijuk hanya contoh awal dan harus dikonfirmasi.
- Formulir kontak saat ini belum terhubung ke layanan pengiriman pesan atau server.
- CSS belum ditambahkan karena tugas Hari 2 meminta kerangka HTML terlebih dahulu.
